# Accessibility checks

Use the keyboard to reach provider selection, upload, document buttons, citations, and the question composer. The selected document button exposes its pressed state.

The conversation uses a live log region. Verify that new replies are announced with a screen reader and that errors are announced without moving focus unexpectedly.

Enter submits a question; Shift+Enter inserts a newline. Input method composition must finish before Enter can submit. Questions are limited to the API's 4,000-character maximum.

Check zoom at 200%, visible focus, and narrow-screen layout when changing styles. These manual checks complement the production build.
